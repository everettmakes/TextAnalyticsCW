\section{Introduction}
This report explores methods for extracting Population, Intervention, Comparison and Outcome (PICO) results from medical abstracts. We extract the PICO results into a predefined schema from the text. An evaluation is carried out on how different strategies effect the quality of extracted data. Extraction of key data from medical text is an important field due to medical decisions contributing to life and death outcomes \cite{landolsi_information_2023}. Alongside recent research in LLMs and expert systems, the need for robust text analytics pipelines is growing \cite{wiest_llm-aix_2024}. This need is what motivates this project. Key challenges faced in this project are how to best prepare text for extraction, what methods to use, and finally how to evaluate these methods. Each of these is covered in detail, justifying our decisions at each stage. The available data used for this project is the ebm-nlp medical abstract corpus. It contains 4,993 abstracts, along with PIO labels. Although, for this task we will aim to extract Comparison results. Since training labels for Comparison are not provided, methods of evaluation will be explored later.
